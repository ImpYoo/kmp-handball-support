Sportradar – Phase Summaries

GET /api/sportradar/phases

ADMIN only. Fetches all phases directly from Sportradar (bypassing the domain layer) and returns a summary per phase: name, matchDayCount, matchCount.
Returns 503 when EXTERNAL_API_ENABLED=false, 502 on upstream failure.

Sportradar – Phase Detail

GET /api/sportradar/phases/{phaseId}

ADMIN only. Returns the full phase including all match days and every match with referee A/B, timekeeper, scorekeeper and delegate.

Sportradar – Phase Matches

GET /api/sportradar/phases/{phaseId}/matches

ADMIN only. Flat list of all matches in the phase. Each match includes timestamp, teams, result, halftime result and all officials (refereeA, refereeB, timekeeper, scorekeeper, delegate).

Sportradar – Single Match

GET /api/sportradar/phases/{phaseId}/matches/{matchId}

ADMIN only. Returns a single match with timestamp, teams, result, halftime result and all officials (refereeA, refereeB, timekeeper, scorekeeper, delegate).

Sportradar – Tournaments

GET /api/sportradar/tournaments

ADMIN only. Lists tournaments from the live Sportradar tournaments feed.

Sportradar – Tournament

GET /api/sportradar/tournaments/{tournamentId}

ADMIN only. Returns a single tournament with all seasons from the live tournaments feed.

Sportradar – Seasons

GET /api/sportradar/tournaments/{tournamentId}/seasons

ADMIN only. Lists all seasons for the given tournament from the live tournaments feed.

Sportradar – Season Detail

GET /api/sportradar/tournaments/{tournamentId}/seasons/{seasonId}

ADMIN only. Fetches live phases from Sportradar for this season and returns a full season detail (label, isHbl, phase summaries with match counts).

Sportradar - Refresh Cache

POST /api/sportradar/refresh

ADMIN only. Clears tournament/fixtures caches and reloads live data from Sportradar.
